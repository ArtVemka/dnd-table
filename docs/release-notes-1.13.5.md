# D&D Стол 1.13.5

Обновление от 1 ноября 2026. Опрос в чате и снимок сцены.

## Опрос

* **/vote** в чате: `/vote Вопрос | Вариант 1 | Вариант 2` (до шести вариантов)
  запускает голосование у всех участников. Панель с кнопками внизу экрана:
  клик голосует, повторный меняет голос, свой вариант подсвечен, счёт у
  каждого варианта вызывается сразу. Голоса видит только мастер. Закрывает
  опрос кнопка «Закрыть опрос» у мастера. Опрос эфемерный: после перезапуска
  стола панели пусты.

## Сценарист

* **Снимок сцены.** В панели фишек две кнопки: «Снимок сцены» запоминает
  раскладку всех фишек (позиции и карты), «Вернуть снимок» возвращает её
  одним действием, с подтверждением. Откат восстановления: Ctrl+Z.
  Снимок эфемерный: переживает только до перезапуска стола.

## Уже было

* Ctrl+K открывает поиск по кампании: реализовано раньше и помечено
  «выполнено» в примечаниях.

## Проверки

* node --check затронутых файлов и смок логики голосов пройдены. Полные
  наборы тестов не запускались: перед выкладкой прогнать `npm test`.

## Установка

* **Портативная сборка.** Папка `D&D Стол.exe` с `data` рядом, архив
  `D&D Стол.zip`.
