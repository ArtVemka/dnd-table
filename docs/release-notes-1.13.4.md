# D&D Стол 1.13.4

Обновление от 1 ноября 2026. Планировщик сцен: вывод всех фишек на показанную
карту одним ходом и один откат.

## Фишки

* **Все на активную карту.** Кнопка над списком фишек: все фишки с других
  карт разом выходят на карту, которую видят игроки, в центр небольшими
  сетками (3 в ряд), чтобы толпа не слиплась в точку. Скрытые заготовки
  остаются скрытыми. Кто уже на активной карте, чтобы не тронулся. Ctrl+Z
  возвращает весь перенос целиком.

## Ограничения

* Перенос работает только на показанную карту: кнопка есть, но сервер
  откажет с «Сначала покажите карту игрокам».

## Проверки

* node --check затронутых файлов пройден. Полные наборы тестов не
  запускались: перед выкладкой прогнать `npm test`.

## Установка

* **Портативная сборка.** Папка `D&D Стол.exe` с `data` рядом, архив
  `D&D Стол.zip`.
