# D&D Стол 1.14.1

Обновление от 1 ноября 2026. Техническое: подъём Electron с 28.3.3 до 45.2.1
(F04 из дорожной карты, закрыт).

## Обновление Electron

* Electron 28.3.3 → 45.2.1, восемнадцать мажорных версий. Внешне приложение
  работает как раньше: прогнаны полный серверный набор (~523 проверки) и
  рендерный пакет через packaged-smoke на собранном exe, включая перенос
  листа, сетку, свет, стены и портативную распаковку архива.
* Замечание по упаковке: архив портативной сборки вырос со 102.3 до 151.0
  МБ: runtime новой версии весит больше, размер игры на диске вырастет так
  же. Это плата за свежий Electron, функционально ничего не меняется.
* Изоляция контекста (preload через contextBridge + ipcRenderer), мост
  Discord, скриншот окна и экспорт сессии на 45 проверены, ломки нет.

## Где брать дистрибутив Electron

* npm держит загрузчик Electron за allow-scripts, поэтому при обычной
  установке дистрибутив не скачивается. Рецепт для новой машины:
  `ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/ node node_modules/electron/install.js`,
  затем `npm run dist:portable` как обычно.
