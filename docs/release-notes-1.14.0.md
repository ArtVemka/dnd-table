# D&D Стол 1.14.0

Обновление от 1 ноября 2026. Начало технической пачки: кампания больше не
раздувается base64 (F29 из дорожной карты).

## Хранение картинок

* При старте стола старые кампании мигрируют автоматически: картинки фишек
  (`imageUrl`) и карт (`url`), сохранённые прямым base64, переписываются в
  файлы кампании (`/files/<имя>`), состояние получает короткую ссылку.
  Это уменьшает размер `campaign.json`, автосохранений и всех рассылок
  сетевого стола и забирает base64 из памяти окна: раньше каждая фишка с
  картинкой держала десятки мегабайт в DOM.
* Миграция одноразовая: после первого подъёма поле уже `/files/`, повторного
  переноса нет. Картинки, чей base64 превысил 10 МБ, остаются как были
  (предел картинок сервера не менялся).
* Аватары легаси не мигрируются: ссылка аватара обрезана лимитом в 2048
  символа ещё при загрузке, декодировать из неё уже нечего.
* Новые картинки и так жили в файлах с прошлых версий: фишки, карты, чат,
  журнал, звук — этой правки не касаются.

## Осталось в пачке 1.14.0 (не в этом выпуске)

* F24 модульный рефакторинг рендерера, F25 ESLint+Playwright, F26 i18n,
  F27 macOS (нужен Мак в наличии), F28 голос/TTS. F25 связана с `npm test`,
  как и F04, поэтому тоже ждёт прогона тестов.

## Проверки

* node --check затронутых файлов и смок миграции на временной папке пройдены
  (две base64-картинки переписаны в `/files/`, готовые ссылки не тронуты).
  Полные наборы тестов не запускались: перед выкладкой прогнать `npm test`.

## Установка

* **Портативная сборка.** Папка `D&D Стол.exe` с `data` рядом, архив
  `D&D Стол.zip`.
