# D&D Стол 1.13.2

Обновление от 31 октября 2026. Малый QoL-пакет: фильтр чата и отчёт по
уже работавшему.

## Чат

* **Только броски.** Кнопка «Только броски» в строке поиска чата прячет
  разговоры, оставляя броски и системные плашки: искать нужную проверку не
  придётся сквозь полтысячи реплик. Действует на живые сообщения на лету;
  после перезапуска фильтр снова выключен.

## Уже было

* Счётчик раундов: подпись «Раунд N» в панели порядка боя, авто-инкремент
  при цикле по всем участникам и сброс на единицу при полном перебросе
  работали с начала.
* Экспорт сессии в Markdown (кнопка в панели кампании, включая чат) и
  автолог jsonl с экспортом в окне журнала добавлены в 1.13.0.

## Проверки

* node --check затронутых файлов пройден. Полные наборы тестов не
  запускались: перед выкладкой прогнать `npm test`.

## Установка

* **Портативная сборка.** Папка `D&D Стол.exe` с `data` рядом, архив
  `D&D Стол.zip`.
