# D&D Стол 1.9.1

Версия про обновления и Discord: установленная Windows-игра теперь сама проверяет GitHub, а друзья видят, кто мастерит и кто играет.

## Discord

* **Присутствие за столом.** В «Настройки» → «Общие» появился тумблер «Показывать игру в Discord». По умолчанию выключен.
* **Мастер и игрок.** Мастер показывает название кампании и число игроков, игрок показывает имя персонажа и «Стол мастера». Время сессии идёт с начала стола.
* **Ничего лишнего.** В Discord не уходят карта, чат, журнал, хиты, билет P2P и внутренние идентификаторы.
* **Windows и Linux.** На Android присутствия нет.

## Установщик и обновления

* **Установщик для Windows.** `DND-Table-Setup-1.9.1.exe` ставит игру в профиль пользователя или для всех, ярлыки создаются автоматически.
* **Автообновление.** Раз в четыре часа приложение проверяет релизы на GitHub, скачивает новую версию и предлагает перезапуститься. «Позже» установит обновление при выходе.
* **Кнопка проверки.** В «Настройки» → «Общие» есть «Проверить обновления» со статусом: проверяю, скачиваю, версия готова, обновлений нет.
* **Портативная версия.** Обновляется вручную: распакуйте новый архив поверх старой папки, `data` не трогайте.
* **Данные.** Установленная версия хранит кампании в `%APPDATA%\dnd-table`, портативная в `data` рядом с exe. При переходе с портативной на установленную папку `data` нужно скопировать вручную.

Установщик пока без подписи, поэтому Windows может показать предупреждение SmartScreen.
