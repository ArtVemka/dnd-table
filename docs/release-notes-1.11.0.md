# D&D Стол 1.11.0

Обновление от 31 октября 2026. Концентрация монстров, броски по таблицам
справочника, слэш-команды чата и свет, который сам следит за часами.
Схема кампании обратно совместима: новые поля фишек и карт необязательны.
Аудио на столе и автоспасброски по области уже работали в обновлениях 1.10.x.

## Стол

* **Автоконцентрация монстров.** В меню фишки поле «Концентрация»: название
  заклинания. При уроне сервер сам бросает d20 против СЛ, которая выше
  (максимум из 10 и половины урона), на провале снимает заклинание и пишет в
  чат. Концентрация героя живёт в листе, как раньше: сервер только готовит
  заявку на бросок.
* **Свет по времени суток.** У карты флаг «Авто-свет по времени суток» в
  панели света. Темноту считает сервер по кривой суток из общих правил:
  рассвет с 6 утра, день с 8 до 17 часов, закат к 21, ночь с 22. Время
  меняется любой сменой часа, включая долгий отдых с его «+8 часов»; карты
  без флага не трогаются, и ручной ползунок темноты тотчас выключает флаг.

## Справочник приключения

* **Броски по таблицам.** У импортированной из Foundry таблицы появились
  строки. Кнопки «Бросить» и «Тайно» в карточке: строку выбирает сервер по
  весам или по диапазону результата формулы таблицы. Открытый бросок виден в
  чате строкой таблицы, тайным живут только мастера. За раз импортируется до
  100 строк на таблицу.

## Чат

* **Слэш-команды.** `/r 1d20+5` — бросок; `/w имя текст` — шёпот (мастер
  адресует игрока, игрок шепчет ведущему); `/hp 4` лечит выбранную фишку
  хода, `/hp -5` ранит; `/ac 17` ставит класс брони; `/help` — подсказка.
  Правки фишек разрешены только мастеру, сервер проверяет. «/» в обычном
  сообщении проходит как текст.

## Ограничения

* Серия урона по монстру каждый раз своя проверка концентрации: заявки на
  бросок, как у героя, у монстра нет.
* Кривая суток дискретная по часу: внутри часа темнота не плавает.
* Таблица без строк командой вернуть нельзя: сервер отвечает «Таблица с
  такими строками не найдена». Редактора строк в справочнике нет, строки
  приходят из импорта.
* `computeDerived`-модификаторов у монстра нет: проверка концентрации фишки
  идёт плоским d20.

## Проверки

* Смок серверной логики (кривая суток, normalizeToken, таблицы, концентрация)
  прогнан одноразовым скриптом; полные наборы тестов в этой сессии не
  запускались — перед выкладкой прогнать `npm test`.

## Установка

* **Установщик для Windows.** `DND-Table-Setup-1.11.0.exe` ставится поверх
  прежней версии.
* **Портативная сборка.** В архиве `DND-Table-1.11.0-windows-x64.zip`:
  папка `D&D Стол.exe`, `portable.txt` и папка `data` рядом с exe.
