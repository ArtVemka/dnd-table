# ROADMAP.ai — машинная версия дорожной карты D&D Стола

> Назначение: контекст для ИИ-агентов (Cursor, Claude Code, Copilot и т. п.).
> Человекочитаемый источник: `ROADMAP.md` (синхронизировать при правках).
> Факты о коде проверены на коммите `9703f56` (v1.10.3, 2026-10-28).
> Идентификация: `F01`–`F29` соответствуют пунктам `п. 1`–`п. 29` в ROADMAP.md.

---

## 0. Инварианты — нарушать запрещено

1. **Сервер авторитарен.** Боевые расчёты, скрытие HP монстров, тайные броски,
   туман по ходам — только в `server/`. Клиент — отображение, не источник истины.
2. **Правила D&D только в `renderer/dnd5e.js`.** Сервер импортирует этот модуль
   (`server/state.js` уже так делает). Дублировать правила в `server/` запрещено.
3. **Новая функция = полный цикл:** клиент emit → валидация в `server/socket.js`
   → нормализация в `server/state.js` + лимит в `LIMITS` → broadcast события.
4. **Обратная совместимость кампаний без миграций:** новые поля необязательны;
   кампания `campaign.json.bak` + 5 копий в `data/backups` не должны ломаться.
5. **Аудио не через `server/image.js`** — тот принимает только `data:image/*`.
6. **Макросы из импорта не исполняются никогда.** Roll20 / D&D Beyond / PDF
   импорт — вне границ. Чужие системы правил не редактируются.
7. **Рендер:** не менять классы/id DOM-узлов без прогона
   `test/renderer-assertions.js` (6678 строк проверок DOM-поведения).
8. **Сетевая модель неизменна:** сервер слушает только `127.0.0.1`, P2P через
   iroh, без VPN/проброса портов/облачного хостинга.
9. **Без TODO/FIXME в коде** и без изменения стека (Electron остаётся).

## 4. Диагноз производительности (2026-10-30, повод для F01–F04)

Симптом: лаги на офисных ПК (встроенная графика, 8 ГБ). Установлено по коду:

1. `requestAnimationFrame` — **0 вхождений во всех `renderer/*.js`**. Отрисовка
   событийная: wheel → `zoomAt()` (`table.js:1778`), `pointermove` протяжки
   шаблона → синхронные `makeTemplate` + `paintTemplates` (`table.js:1836–1839`).
2. `--pointer-x` обновляется на каждый `pointermove` (`table.js:1663–1668`)
   → непрерывный recalc+repaint декоративного слоя.
3. Темы: 431 совпадение `blur/backdrop-filter/gradient/shadow/color-mix`
   (`09-theme-studio.css`: 217, `08-theme-layer.css`: 214) — дорого на iGPU.
4. Репейнт-конвейер тяжёлый: `paintFog + paintLight + paintWallOverlay +
   paintSurface + paintTemplates` вместе (`table.js:1791–1800`); свет —
   рейкастинг `castRay` (`dnd5e.js:727`).
5. Карты — base64 в JSON кампании (до 10 МБ/файл): паузы GC на слабом CPU.

## 7. Не-цели

- Двусторонняя синхронизация с Foundry, обратная выгрузка, редактирование
  чужих систем правил.
- Исполнение макросов — никогда.
- Импорт Roll20 / D&D Beyond / PDF (пересмотр — только при явном спросе).
- Облачный хостинг столов, VPN, проброс портов.
- Смена стека (Electron, JS) — закрыто обсуждением 2026-10-30: узкое место
  в архитектуре отрисовки (F01–F03), а не в языке.
- Серверные гарантии по зрению: зрение считается на клиенте, защита от чтения
  состояния не обещается (принято в 1.10.3).
- `playerKey` — не пароль: доступ к компьютеру/файлу кампании = вход под
  игроком.
